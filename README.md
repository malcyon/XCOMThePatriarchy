# XCOMThePatriarchy

What is this? 
---
This is a mod for XCOM 2. It can be downloaded here:

http://steamcommunity.com/sharedfiles/filedetails/?id=624102176

What does it do?
---
Changes the ratio of males to females in the Character Pool from 50/50 to 80/20. 

Customizable male/female ratio
---
If you want a different ratio than 80/20 (say, 20% males and 80% females, you can do that, too, by editing this mod's INI file. 

On my machine, the INI file is located here: 

C:\Program Files (x86)\Steam\SteamApps\workshop\content\268500\624102176\Config\XComThePatriarchy.ini

Change the folowing line to any number between 1 and 100: 

PERCENT_MALE=80 

Does this conflict with any other mods?
---
This mod overwrites the XGCharacterGenerator class. Any mods that also touch that class probably won't play well with this mod.
